Ask Data: стороннее расширение

Сторонний интерфейс Ask Data: границы пилота и критерии качества.

ЭкспериментНовоеСтороннее расширение6 минСверено 2026-11-06

superset-nl-explorer — отдельный проект MIT Open Learning с интерфейсом исследования данных на естественном языке. Он не является встроенной возможностью Apache Superset. В репозитории описана интеграция через LiteLLM.

Зачем пробовать

Такой интерфейс может помочь сформулировать запрос, найти нужную визуализацию или изучить данные в диалоге. Его полезность нужно оценивать на ваших вопросах и определениях метрик. Сам факт ответа на русском ещё ничего не говорит о корректности расчёта.

Подготовка

Инженер должен проверить совместимость текущего расширения с установленным Superset и зафиксировать версию кода. Уточните поддерживаемую модель, способ аутентификации, передаваемые поля, журналы и возможность отката. Используйте отдельный стенд и синтетические данные.

Не переносите команды установки из старой статьи: структура расширения и требования могут измениться. Точка входа для установки — README выбранного коммита в репозитории проекта.

Мини-пилот для аналитика

Составьте десять вопросов: три простых итога, три разбивки, два сравнения периодов, один вопрос без данных и один вне разрешённой области. Для каждого вручную подготовьте контрольный ответ. Просите систему объяснять источник, период и формулу.

Записывайте не только долю совпадений, но и типы ошибок: неправильный JOIN, пропущенный фильтр, неверная агрегация, выдуманное объяснение. Повторите неоднозначный вопрос несколько раз. Отметьте, где потребовалось вмешательство аналитика.

Критерий полезности

Сравните время выполнения одинаковой задачи вручную и с помощником, включая проверку ответа. Если время экономится только за счёт пропуска сверки, результат пилота нельзя считать положительным.
