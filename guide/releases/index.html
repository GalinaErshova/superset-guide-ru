Что изменяет работу с оформлением

Начиная с 6.0 официальная документация описывает систему тем на основе токенов Ant Design v5. Это повод пересмотреть накопленные CSS-правила: часть задач теперь можно решать штатными темами. Не переносите настройки из документации Next в 6.1 без проверки доступности.

Как читать новости

Новая функция в PR ещё не доступна пользователю. Слитый коммит в master ещё не гарантирует стабильный выпуск. Даже после выхода релиза возможность может требовать прав, зависимостей или включённого флага. Поэтому рядом с новостью нужны версия, источник и практический вывод.

В журнале 6.1.0 стоит дата 1 мая, а GitHub опубликовал релиз 13 мая. На этой странице используется дата публикации GitHub.

Проверка дашборда после обновления

  1. Выберите контрольный набор экранов и сохраните их экспорт до обновления.
  2. Зафиксируйте данные, период и роль пользователя для сравнения.
  3. Сверьте метрики и табличные результаты.
  4. Проверьте фильтры, их область действия, сохранённые ссылки и доступ коллеги.
  5. Проверьте темы, CSS, подписи, подсказки и экспорт.
  6. Измерьте время загрузки в одинаковых условиях.

Обновление сервера и резервное копирование выполняет администратор. Экспорт дашбордов не заменяет резервную копию метаданных установки.
