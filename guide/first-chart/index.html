Постройте первый график: выручка по регионам

Построить первый график и сверить число с исходными данными.

СтабильноНовое6.110 минСверено 2026-11-06

Цель: получить сохранённый столбчатый график, где каждый столбец показывает сумму выручки одного региона. Здесь важно связать вопрос бизнеса с настройками запроса: «Сколько выручки принёс каждый регион за весь учебный период?»

Понадобятся проверенный датасет sales и права создания графиков. Если вы ещё не проверили типы колонок и отсутствие дубликатов, вернитесь к подготовке данных. Названия элементов приведены для английского интерфейса; набор контролов зависит от выбранного типа визуализации.

Настройте запрос в Explore

  1. В Datasets нажмите название sales. Если открылась другая страница, используйте Charts → + Chart, выберите этот датасет и перейдите к выбору визуализации.
  2. В каталоге визуализаций найдите Bar Chart — столбчатую диаграмму. Выберите вариант на основе ECharts, поддерживающий категориальную ось. В разных сборках название может содержать Time-series; ориентируйтесь на наличие поля X Axis, в которое можно выбрать region.
  3. На вкладке Data укажите X Axis → region. Если редактор использует Group by для категорий, задайте регион там. Нам нужна одна группировка по региону, без второго разбиения.
  4. В Metrics добавьте показатель: колонка revenue, агрегация SUM. Удалите оставшийся по умолчанию COUNT(*), если он добавлен: количество строк отвечает на другой вопрос.
  5. Выберите Time range → No filter. Удалите фильтры региона, категории и другие ограничения. Контрольная сумма курса относится ко всем заказам.
  6. Проверьте Row limit: лимит должен вмещать все регионы. Для маленького учебного набора можно оставить обычное значение по умолчанию, если оно заведомо больше числа категорий.
  7. Нажмите Run / Run Query. После изменения контролов не считайте прежний рисунок результатом нового запроса, пока запрос не выполнен.

Сделайте график читаемым

На вкладке Customize задайте подпись оси значений «Выручка, у. е.». Не добавляйте знак рубля: в учебном файле валюта не задана. При необходимости поверните длинные подписи категорий или используйте горизонтальное расположение столбцов, если выбранный график его поддерживает.

Начните с одной спокойной палитры. Разные цвета у каждого региона полезны только тогда, когда цвет помогает прослеживать один и тот же регион в нескольких графиках. Цвет не заменяет подписи. Убедитесь, что шкала и формат числа не создают впечатления иной величины: сокращение «156k» означает 156 тысяч, а не 156 единиц.

Сохраните результат

Нажмите Save, выберите Save as и назовите график «Выручка по регионам · учебный». Если появится выбор дашборда, пока можно сохранить график без добавления либо создать свой учебный дашборд. В следующем уроке мы соберём его отдельно.

Закройте редактор и найдите график через Charts. Откройте его снова: сохранённые ось, метрика и период должны соответствовать выполненному упражнению. Внесение изменений в Explore и сохранение графика — отдельные действия.

Проверьте смысл результата

Переключитесь на табличное представление результата или откройте Data preview. Сложите выручку всех показанных регионов: без фильтров должна получиться 156 000. Если часть категорий скрыта лимитом, такая сверка неполна.

  • Равные маленькие числа могут означать COUNT, выбранный вместо SUM.
  • Пустой график часто объясняется временным фильтром, несовместимым типом колонки или отсутствием доступа.
  • Значение больше контрольного требует проверить дубликаты и группировку исходного набора, а не подправить формат числа.

Упражнение и проверка

Создайте второй вариант через Save as: «Затраты по регионам · учебный». Замените только метрику на SUM(cost) и подпись оси на «Затраты, у. е.». Сумма категорий должна стать 98 000, а исходный график выручки должен остаться неизменным. Совпадение контрольных сумм и наличие двух самостоятельных графиков — критерий готовности.

Далее: собираем дашборд.
