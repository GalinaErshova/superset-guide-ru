Словарь интерфейса

Английские названия элементов интерфейса с русскими пояснениями.

СтабильноНовое6.15 минСверено 2026-11-06

Английские подписи оставлены рядом с русскими: по ним проще найти элемент в установке без локализации. В корпоративных сборках названия и доступные пункты могут отличаться.

Термин Что означает для аналитика
Database / Connection Настроенное подключение к источнику данных
Schema Схема внутри базы; часть адреса таблицы
Dataset Набор данных, его колонки и сохранённые метрики
Physical dataset Датасет на основе таблицы или представления в источнике
Virtual dataset Датасет на основе сохранённого SQL-запроса
Column Поле данных, например регион или дата заказа
Dimension Разрез группировки: регион, месяц, категория
Metric Агрегированный показатель, например сумма выручки
Calculated column Выражение для отдельной строки
Explore Рабочее место настройки одного графика
Chart График, таблица или карточка показателя
Dashboard Экран из графиков, текста и фильтров
SQL Lab Среда выполнения SQL-запросов
Time range Период отбора исходных строк
Time grain Шаг группировки времени
Filter scope Графики, на которые распространяется фильтр
Cross-filter Фильтрация других графиков через выбранный элемент визуализации
Row limit Ограничение числа возвращаемых строк результата
Cache Сохранённый результат для повторного использования
RLS Ограничение доступных строк по правилам доступа
Theme Общие правила оформления интерфейса
Feature flag Переключатель возможности в настройках установки
Release candidate / RC Кандидат в релиз для проверки перед стабильным выпуском
MCP Протокол, через который AI-клиент вызывает разрешённые инструменты сервиса

Не путайте

Датасет не обязательно копирует данные в Superset. Сохранить график и открыть к нему доступ коллегам — разные действия. Фильтр на экране не заменяет правила ограничения доступа к данным.
