Источники и русскоязычные аналоги

Официальные документы, русскоязычные аналоги и дополнительные материалы.

СтабильноНовое6.15 минСверено 2026-11-06

Основа справочника — официальная документация Apache Superset с указанием версии. Практические рекомендации и учебные данные подготовлены для этого сайта. Это независимый ресурс, не официальная русская документация Apache Software Foundation.

Основные источники

  • Документация пользователя 6.1.0 — первый дашборд, исследование данных, SQL и AI.
  • Документация администратора — установка, темы, безопасность и MCP.
  • Релизы и исходный код — проверка того, что действительно выпущено.
  • Preset — статьи участников экосистемы. Функции Preset Cloud могут отличаться от Apache Superset.
  • Community Resource Library — указатель материалов сообщества, а не гарантия их актуальности.
