# Codex и ваш стенд Superset

Codex можно использовать как помощника в разработке: готовить SQL, разбирать настройки, редактировать CSS и конфигурацию в Git. Для работы с живыми объектами нужен доступ к вашему Superset через доступный интерфейс или MCP. Наличие установленного Superset само по себе не подключает его к Codex.

## Два способа работы

**Через файлы проекта.** Дайте Codex репозиторий с SQL, описаниями датасетов, темами и конфигурацией без секретов. Помощник сможет готовить изменения в отдельной ветке. Применение на стенде и проверка результата — отдельные шаги. Работа с файлами не требует включать встроенного AI-ассистента в Superset.

**Через MCP.** Администратор запускает MCP-сервер поддерживаемой сборки Superset. Codex подключается к нему как клиент. Возможные операции определяет сервер: перечень дашбордов, исследование датасетов, выполнение запросов, создание графиков и другие инструменты. Сначала проверьте фактически доступный список, а не обещания из чужой статьи.

## Что подготовить

- Версию и способ установки Superset.
- Адрес стенда, достижимый из среды выполнения Codex.
- Отдельную учётную запись с правами на учебную область.
- Настроенную аутентификацию MCP и адрес endpoint, если выбран этот путь.
- Тестовый датасет и один дашборд, который разрешено изменять.
- Git-репозиторий для SQL, темы и документации изменений.

Локальный адрес сервера внутри контейнера и адрес, доступный с ноутбука, могут различаться. Стенд в VPN требует рабочего сетевого пути. Не публикуйте MCP без аутентификации ради удобства подключения. Пароли и токены не нужно вставлять в учебные статьи, Git или текст задания.

## Подключение клиента

Официальная документация Codex описывает управление MCP через CLI и конфигурацию. Схема команды для уже настроенного HTTP-сервера:

```text
codex mcp add superset --url https://YOUR-HOST/mcp
codex mcp list
```

`YOUR-HOST` нужно заменить настоящим адресом. Эта команда не запускает сервер, не выдаёт права и не настраивает аутентификацию за вас. Способ входа должен соответствовать конфигурации Superset. Наличие записи в списке ещё не доказывает успешный вызов инструмента.

## Первый проверяемый результат

Поручите прочитать структуру учебного датасета и объяснить метрику выручки. Затем попросите получить сумму с явно указанным периодом и сравните её с независимым SQL. Только после этого расширяйте сценарий до создания одного учебного графика.

Пример задания после подтверждения разрешений:

> На тестовом датасете sales создай отдельный график выручки по регионам с префиксом «Учебный». Не изменяй существующие объекты. Покажи формулу и фильтры. Сверь общий итог с 156000 и верни ссылку на новый график.

Доступность создания зависит от инструментов конкретного MCP-сервера и прав пользователя. Если записи нет, можно подготовить SQL и параметры графика для ручного применения. Подключение и создание объектов в рамках подготовки этого справочника не выполнялись.
