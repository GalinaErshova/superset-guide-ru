# Источники и русскоязычные аналоги

Основа справочника — официальная документация Apache Superset с указанием версии. Практические рекомендации и учебные данные подготовлены для этого сайта. Это независимый ресурс, не официальная русская документация Apache Software Foundation.

## Основные источники

- [Документация пользователя 6.1.0](https://superset.apache.org/user-docs/6.1.0/intro/) — первый дашборд, исследование данных, SQL и AI.
- [Документация администратора](https://superset.apache.org/admin-docs/6.1.0/intro/) — установка, темы, безопасность и MCP.
- [Релизы](https://github.com/apache/superset/releases) и [исходный код](https://github.com/apache/superset) — проверка того, что действительно выпущено.
- [Preset](https://preset.io/blog/) — статьи участников экосистемы. Функции Preset Cloud могут отличаться от Apache Superset.
- [Community Resource Library](https://github.com/apache/superset/wiki/Community-Resource-Library) — указатель материалов сообщества, а не гарантия их актуальности.

| [RT.DataVision](https://tdata.tech/products/datavision) | Русскоязычный продукт на основе Superset | Собственные доработки и версия поставки могут отличаться |

## Как используем материалы

Ссылки ведут к авторам. Сайт не воспроизводит чужие статьи целиком и не выдаёт сторонние расширения за части Apache Superset. Если источник изменился или инструкция не подходит вашей версии, укажите ссылку на страницу и номер версии в сообщении об ошибке.
