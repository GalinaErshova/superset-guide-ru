# Дашборд, который можно прочитать

Хороший экран помогает принять решение. До выбора цветов запишите: кто читает дашборд, какой вопрос задаёт и какое действие сможет выполнить после просмотра.

## Соберите историю

В верхней части разместите название, период и ключевые итоги. Ниже покажите динамику и основные причины изменений. Детальную таблицу оставьте для проверки конкретных строк. Это рекомендация по композиции, а не обязательный шаблон Superset.

На учебном дашборде «Продажи» достаточно трёх блоков: общая выручка, выручка по месяцам, сравнение регионов. Прибыль можно добавить после согласования её определения. Не заполняйте свободное место графиками без вопроса.

## Подписи важнее декора

Вместо «Chart 12» напишите «Выручка по регионам, у. е.». Для процентов поясните знаменатель. Для план-факта укажите источник плана. Добавьте текстовый блок с определением показателей, источником и правилом обновления данных. Время обновления страницы само по себе не означает свежесть данных в хранилище.

## Цвет и доступность

Используйте один цвет для одной сущности во всех графиках. Для статуса добавляйте подпись, чтобы смысл не зависел только от различения красного и зелёного. Проверьте контраст подписей, размер шрифта и длинные названия категорий. Посмотрите экран в тёмной теме, если пользователи её включают.

## Проверка перед передачей

1. Откройте экран на обычном ноутбуке и при увеличении масштаба браузера.
2. Убедитесь, что нужные фильтры заметны и их текущее состояние понятно.
3. Выберите категорию без данных: пустой результат должен быть объяснимым.
4. Проверьте заголовки, единицы, периоды и точность округления.
5. Попросите коллегу назвать главный вывод без ваших пояснений.

Если коллега сначала спрашивает, что означает число, улучшайте подпись. CSS не исправит неопределённую метрику.
